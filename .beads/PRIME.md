# The task store in this repository

This is what `bd prime` prints here, at the start of every session and before every compaction, in
place of its own text. It states no rule. Each rule an agent follows here has the one home that
`CLAUDE.md` § Rules for agents live in tracked files, and nowhere else names, and where this file
and `CLAUDE.md` disagree, `CLAUDE.md` wins.

Before a `bd` command, read where its rules live:

- `CLAUDE.md` § The task store: what goes in the tracker, and how it is written.
- `CLAUDE.md` § Git workflow: commits, pushes and pull requests.
- `CLAUDE.md` § Bash command style: how a command is run.
- `CLAUDE.md` § Product work runs as OpenSpec-format changes: a product change's epic and tasks.
- `.claude/skills/bead/SKILL.md`: an issue worked from its claim to its close.

A command's flags are in `bd <command> --help`.
